# Avatar model

Put your VRM file here as `avatar.vrm`. This folder is git-ignored (except this
README) because avatar licenses vary and the files are 10-30 MB.

1. Go to https://hub.vroid.com/ and find a model whose page shows a download
   button and whose license allows personal use (check "Avatar use" and
   "Redistribution" on the model page; for a public demo video, make sure the
   license allows it and credit the author).
2. Download it, rename it to `avatar.vrm`, and save it in this folder.
3. Reload the page.

Both VRM 0.x and VRM 1.0 models work. Later you can export your own from
VRoid Studio (File > Export as VRM).
